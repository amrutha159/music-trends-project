# The Evolution of Music

An interactive dashboard exploring how music trends have changed across decades.

## Features
- Filter songs by year range.
- Compare the number of songs across decades.
- Explore changes in danceability, energy, loudness, and song duration.
- Compare relationships between music features.

## Tools
- Python
- pandas
- SQL and SQLite
- Plotly
- Streamlit

## Running the Project
The original dataset is not included in this repository. To run the dashboard, you will need a compatible copy of the dataset and must set up the local SQLite database.
